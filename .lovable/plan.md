
## Goal

When a document is completed, embed the owner's signature image directly where the `{{owner_signature}}` token lives in the original legacy PDF (currently rendered as the literal text `[Owner Signature Pending]`). Remove the appended "Countersignatures" page — the composed PDF should look identical to the original with the placeholder text replaced by the owner's signature.

## Approach

Legacy PDFs were generated by `src/lib/onboarding/generateSignedPdf.ts`, which writes the literal string `[Owner Signature Pending]` at the `{{owner_signature}}` token location. We locate that text in the PDF and paint the owner's captured signature over it.

### 1. Add `pdfjs-dist` for text-position discovery

Add `pdfjs-dist` as a dependency. Use its `getTextContent()` per page to find text items whose string is (or contains) `[Owner Signature Pending]`. The item's `transform` matrix + `width`/`height` gives us the on-page coordinates in PDF user space (bottom-left origin), which pdf-lib uses directly.

### 2. Rewrite `src/lib/documents/composeCompletedPdf.ts`

Replace the current "append a Countersignatures page" logic with an inline-replacement path:

- Load the legacy PDF into pdf-lib (`PDFDocument.load`) and separately into pdfjs (`getDocument`).
- For each page, run `getTextContent()` and collect items whose `str` matches `[Owner Signature Pending]` (exact match; the generator emits it as a single text run).
- For every match, on the matching pdf-lib page:
  - Draw a white rectangle covering the placeholder's bounding box (from the pdfjs transform) so the placeholder text is hidden.
  - Embed the owner signature PNG (`document_signatures.signature_data_url` for the signer whose `role_label = 'owner'`) via `embedPng`, and draw it anchored at the placeholder's baseline, sized to a fixed height (~28pt) with proportional width, clamped so it never overruns the page.
- Save and upload via the existing `finalize-document-instance` edge function (unchanged).

If no `[Owner Signature Pending]` occurrence is found (very old templates), fall back to drawing the signature in the page's bottom margin so we never silently drop it, and log a console warning.

Native (non-legacy) instances: no source PDF exists, so keep the current stand-alone signature certificate rendering as-is for that branch only.

### 3. Delete the countersignature page helper path

Remove the `renderSignaturesPage` call and `Countersignatures` headline branch from the legacy path. The helper stays only for the native-instance branch.

### 4. Regenerate stored PDFs

Existing three backfilled instances already have `pdf_storage_path` set to the old "with countersignature page" file. To force recomposition, clear `pdf_storage_path` for any `document_instances` row where `metadata->>'backfilled' = 'true'` (single one-line migration). The next visit to the signing workspace will re-run `composeCompletedPdf` and overwrite the stored PDF with the corrected version.

## Technical Notes

- pdfjs-dist worker: use the "legacy" build (`pdfjs-dist/legacy/build/pdf.mjs`) and disable the worker (`disableWorker: true` / no `workerSrc`) to avoid Vite worker bundling issues in the browser.
- Coordinate math: `transform = [a,b,c,d,e,f]`; the placeholder's bottom-left is `(e, f)` and height is `transform[3]` (font size). Width comes from the item's `width` (already in PDF units).
- Signature sizing: target height 28pt, width = `min(pageWidth - x - margin, sigAspect * 28)`; draw at `(x, f - 4)` so it sits on the same baseline as the removed text.
- We only replace `[Owner Signature Pending]` — the driver signature already lives in the legacy PDF as an embedded image and is untouched.
- No schema changes beyond the one-line reset of `pdf_storage_path` for backfilled rows.

## Files Touched

- `package.json` / `bun.lock` — add `pdfjs-dist`
- `src/lib/documents/composeCompletedPdf.ts` — inline replacement logic; drop countersignature page for legacy branch
- `supabase/migrations/<new>.sql` — `UPDATE document_instances SET pdf_storage_path = NULL WHERE metadata->>'backfilled' = 'true';`

2. Download the completed PDF and confirm the `[Owner Signature Pending]` text is gone and the owner's signature image appears exactly where it was, above `Authorized Corporate Signature`.
3. Confirm the PDF has no extra "Countersignatures" page appended.
4. Repeat for the other two backfilled instances.
